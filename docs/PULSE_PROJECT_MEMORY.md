## CURRENT STATE

Полноценный музыкальный веб-сервис (тёмная тема, RU). Каталог: настоящие
записи СНГ: **762 трека, 29 исполнителей, 78 альбомов** (проверено smoke-тестом;
12.09 волна 7 добавила 130 треков, 14.09 из волн убраны 11 дублей-синглов,
совпадавших с альбомными версиями).
Работают: главная, поиск, библиотека-витрина, лайки, история без дублей,
профиль, статистика месяца (топ-5), страницы артистов/альбомов/плейлистов,
CRUD плейлистов, очередь, шаффл, повторы, громкость, свои аудиофайлы,
полные версии через YouTube. Всё запускается с HTTP 200, консоль чистая.

## ARCHITECTURE

- Никаких сборщиков и зависимостей. Vanilla JS, 7 файлов, порядок в index.html:
  `data.js → art.js → player.js → yt.js → app.js` (+ `styles.css`).
- Каждый файл: IIFE, общение через `window`: `PULSE_DATA`, `PulseArt`,
  `PulseEngine`, `PulseYT`.
- SPA без роутера-библиотеки: hash-роуты (`#/home`, `#/artist/:id` …),
  рендер через `render()` с токеном `routeToken` против гонок, скелетон 300мс.
- Один делегированный `click`-обработчик на `document` по `data-action`.
  FAB внутри карточек перехватываются отдельно; ссылки `a[data-link]`
  внутри строк треков не запускают воспроизведение.
- `data.js`: единственный источник каталога. `app.js` (~1510 строк): вся логика.

## ROUTES

`home`, `search` (есть UI сверху; прямых ссылок в nav нет, осознанно),
`library` (витрина-секции), `files` (свои файлы, вход из библиотеки),
`liked`, `history`, `artist/:id`, `album/:id`, `playlist/:id`,
`profile`, `stats`. Неизвестный хэш → home. Title документа обновляется.

## DATA

- Track: `id,title,credit,artistId,albumId|null,rel,fullMs,year,genre,
  seed,pal,art(600px),preview(m4a),apple,yt?(11 символов)`.
- Artist: `id,name,genre,seed,pal,verified,bio,wiki?,apple(artistId)`.
- Album: `id,title,artistId,year,trackIds[],apple`.
- Playlist: демо (4, `editorial`) + авто `this-<artistId>` (`auto`, пересборка
  при старте) + пользовательские (`u<ts>`, `pal/seed`, удаляемы только свои).
- `CHART` (топ-8 руками, без выдуманных счётчиков), `LINEUP` (составы
  мульти-артистов: имя + id в каталоге или без), `THIS_PREFIX="this-"`.
- Локальные треки пользователя ((`local:true`, `artistId:"local"`, object URL))
  живут только в рантайме + IndexedDB, в `data.js` их нет.

## LOCAL STORAGE

- `pulse.v3`: likes, likedAlbums, playlists, history(100), volume, muted,
  shuffle, repeat, profile{name,variant,seed,avatar?,fresh}, stats{ММ:{artist:sec}}.
- Миграция: profile подхватывается из `pulse.v2`; битые id чистятся;
  подряд-повторы истории схлопываются при загрузке.
- `pulse.ytids`: кэш videoId (`{trackId: ytId}`).
- IndexedDB `pulse-files`: свои аудиофайлы (`{id,title,credit,seed,pal,fullMs,year,blob}`).

## AUDIO

- `player.js`: превью iTunes (~30с) через `<audio>`: play/pause/seek/
  volume/mute, `timeupdate`/`loadedmetadata`/`ended`/`error`, errorStreak,
  promise-catch автоплея (хук `onBlocked`).
- `yt.js`: полные версии через официальный IFrame API (ленивая загрузка,
  15с таймаут, `pending`, sync громкости). Ошибка/блок → фолбэк на превью.
- `app.js`: `AE()` = активный движок (`ytMode ? ytEng : engine`); громкость/
  мут применяются к обоим; статистика тикает 1с только при реальном
  воспроизведении; `stop-all` (пауза + сброс); repeat one/all/off; shuffle.

## EXTERNAL APIS

| Что | Где | При ошибке |
|---|---|---|
| iTunes preview CDN (`audio-ssl…`) | player.js | тост + авто-next; ≥3 подряд → пауза + тост |
| Обложки mzstatic 600px | все `img` | `onerror` → генеративный арт / скрытие |
| YouTube IFrame API | yt.js (lazy) | фолбэк на превью + тост |
| Piped search API (резолвер ID) | `ytResolve` | остаётся ссылка на поиск |
| Каналы YouTube (6 шт.: kishlak, jahkahlib, madk1d, basta→@gaz_live, zivert, jony) + поиск | страницы артистов | обычные внешние ссылки |

Скачивания чужой музыки нет и не будет (решение зафиксировано).

## DESIGN SYSTEM

Фон `#0d0d0e`, поверхности `#141415/#171718`, текст `#f3f0e6`,
акцент жёлтый `#ffce2e`. Плоские карточки 10px, моноширинные цифры/кикеры,
жёлтая плашка плеера сверху 2px. Брейкпоинты: 560 (топбар), 860 (мобильная
навигация + компактный плеер 150px), 1080, 1600. `prefers-reduced-motion`
учтён. Фокус `:focus-visible` жёлтый; skip-link; aria-labels на всех
икон-кнопках; `aria-pressed` на состояниях.

## DECISIONS

- Без зависимостей и сборки: открывается дабл-кликом и с http.server.
- Честность данных: никаких выдуманных счётчиков/слушателей; чарт задан руками.
- Превью 30с + полные версии только легально (YouTube/ссылки/свои файлы).
- Не-каталоговые гости фитов: «Нет в Pulse: только фит», без битых ссылок.
- MADKID (JP аниме-группа) в СНГ-каталог не берём.
- Публикация: этот репозиторий на GitHub Pages; исходники каталога в `data.js`.
