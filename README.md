# Pulse — музыкальный каталог с плеером

Свой пет-проект: каталог СНГ-музыки на чистом HTML/CSS/JS, без бэкенда.
Внутри: **762 трека, 29 исполнителей, 78 альбомов**, поиск, фильтры, профили артистов, плейлисты и свой аудиоплеер.

## Честно про аудио
- Превью в плеере — 30-секундные отрывки через iTunes Search API.
- «Полная версия» идёт через внешний YouTube-резолвер (Piped API) — сервис может отвалиться, это внешняя зависимость.
- История, лайки, плейлисты и статистика — в localStorage вашего браузера.

## Архитектура
- `data.js` — каталог (762/29/78), отделён от логики.
- `app.js` — роутинг вью, состояние, поиск.
- `player.js` — плеер и очередь.
- `yt.js` — резолвер полной версии через YouTube.

## Как запустить
Просто открыть `index.html` или поднять локальный сервер:
```bash
python -m http.server 8137
```
Работает и с `file://`, и с GitHub Pages.
