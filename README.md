# Pulse — музыкальный сервис (СНГ)

> Учебный веб-проект (pet-project) — демонстрация вёрстки и кода, **не коммерческий заказ**.

Статический музыкальный сайт: каталог из 762 треков / 29 исполнителей / 78 альбомов, встроенный аудиоплеер, поиск и фильтры, профили артистов, плейлисты и статистика прослушиваний. Превью 30 сек — iTunes, полные версии через YouTube-резолвер.

🔗 **[Открыть на GitHub Pages](https://Detroll1.github.io/pulse/)**

## Стек
HTML / CSS / vanilla JS · data-каталог · без фреймворков

## Запуск локально
Статический сайт — просто открой `index.html` или подними локальный сервер:
```bash
python -m http.server 8124
# → http://127.0.0.1:8124
```

## Структура
Один входной `index.html`, стили и скрипты рядом. Данные и логика — в JS без завусеженности от бэкенда: сайт полностью работает из коробки.
